# Freeze and private-file gate for PriceRunner variant audit sampler

This superseding Draft PR keeps the exact pair-selection rule in the prospective protocol. No UCI rows or reviewer judgments have been read here. Run the sampler only after a separate person has inspected the source acquisition, Python 3.11 environment, protocol, code and ZIP/CSV hashes, and a timestamped external record that existed before any pair was selected or viewed.

The private freeze attestation must contain the exact clean checkout commit and SHA-256 of the script, protocol, ZIP and CSV. The external anchor URL must be the exact commit permalink in this repository. It must name `selection_operator_github_login`. Its `manual_review` object must name a reviewer distinct from that operator and from the repository owner, a GitHub comment permalink in this repository, a prior UTC review time, the same commit/hash fields and Python version `3.11`. The operator must open that comment and verify its author, content, edit history and timestamp against the actual files. The program checks only the local declaration's shape and field equality. It records `operator_declared_manual_review_not_machine_verified` in the private manifest; a fabricated URL can still pass a local syntax check.

Set `TMPDIR` to a private location outside every Git checkout. The CLI rejects a Git worktree in either the SQLite temporary root or private manifest path, including resolved symlink aliases, before reading source rows. A complete selection can still require substantial disk and time because the protocol allows up to 623,415,705 unordered source-offer pairs before deduplication. Allocate an isolated private disk and runtime budget, preserve failure receipts, and treat disk/time failure as incomplete; never publish partial 50+50 results.

The frozen source hashes are internal repeat-run receipts, not an independently published official checksum. Source acquisition rights and byte provenance still require separate review. Never publish the manifest, titles, offer IDs or completed individual forms in a PR. This tool is a title-evidence platform-cluster diagnostic, not physical SKU truth, matcher precision/recall, sales or demand forecasting.
