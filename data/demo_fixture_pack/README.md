# BridgeTrend OpenCV Demo Fixture Pack

This directory contains 24 deterministic, project-generated images covering six
closed-loop evidence cases:

1. exact product match;
2. close substitute;
3. shared visual style;
4. low-quality query followed by a better view;
5. ambiguous candidate ranking;
6. unsupported match.

The images contain no third-party photography, trademarks, or marketplace
screenshots. They are regenerated by:

```bash
PYTHONPATH=src python scripts/generate_demo_fixture_pack.py \
  --output-dir data/demo_fixture_pack
```

`cases.json` records the provenance, precomputed retrieval inputs, expected safe
decision, and permitted evidence roles. `SHA256SUMS` makes the 24 generated image
artifacts independently verifiable. `contact_sheet.png` is a visual QA aid.

The pack is released as CC0-1.0 for tests and demonstrations. It is not training
data and its six expected outcomes are not a claim of real-world accuracy.
